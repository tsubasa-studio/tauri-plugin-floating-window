## Default Permission

Default permissions for the floating-window plugin

#### This default permission set includes the following:

- `allow-check-permission`
- `allow-request-permission`
- `allow-create`
- `allow-show`
- `allow-hide`
- `allow-move-window`
- `allow-destroy`
